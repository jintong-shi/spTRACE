# Example reference set (generated)

Generated by `sptrace-make-example-reference --seed 0`.

`gene_order.csv`, `chr_lengths.csv`, `celltype.tsv` and `mapped_snps.csv` are
subsampled from the real annotation in `data/reference/`.

`counts.tsv` and `cnv_catalog.csv` are **synthetic stand-ins**. They exist so
the pipeline runs end-to-end without the large or access-controlled inputs.
Do not use them to produce benchmark results -- the count matrix has no
biological covariance structure and the CNV segments come from a toy
distribution, not from observed tumours. See `data/reference/README.md`.
